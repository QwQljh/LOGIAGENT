# LOGIAGENT

The LOGIAGENT REST API testing tool is in [`logiagent/`](logiagent/).

This repository contains tool source code, Dockerfiles, configuration and deployment instructions. Model weights and saved Docker images are excluded from Git. The preparation script builds and starts the local Ollama Qwen3-14B model before the normal RESTGym b/l/v/a steps.
